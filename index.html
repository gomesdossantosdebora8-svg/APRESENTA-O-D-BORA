Matéria 01

Desenvolvimento para Web

Foco na construção de interfaces seguras. Aprendemos a validar entradas de formulários no front e back-end para impedir ataques destrutivos.

Vetor de Ataque Principal: XSS & Injeção

Scripts maliciosos injetados diretamente no navegador do usuário por falta de sanitização de inputs.

Exemplo Prático: Defesa contra XSS (Sanitização)

// Sanitização de entrada em JavaScript
function escaparHTML(str) {
  return str.replace(/[&<>'"]/g, tag => ({
    '&': '&amp;', '<': '&lt;', '>': '&gt;'
  }[tag] || tag));
}

Essa técnica impede que códigos em tags <script> sejam interpretados e executados pelo navegador.

Matéria 02

Redes de Computadores

Estudo de protocolos TCP/IP, roteamento, sub-redes e o tráfego seguro de dados entre servidores e estações de trabalho.

Vetor de Ataque Principal: Sniffing & MitM

Interceptação de pacotes de rede não criptografados trafegando na rede local.

Mitigação: Uso de HTTPS e Firewall

Criptografia em Trânsito (TLS 1.3) Ativo
Segmentação por VLANs Configurado

Garante confidencialidade e integridade fim a fim nos pacotes transmitidos.

Matéria 03

Linguagem de Sistemas

Desenvolvimento de algoritmos estruturados e lógicos com foco em tratamento rigoroso de exceções e controle estrito de memória.

Vetor de Ataque: Buffer Overflow

Estouro de buffer por alocação incorreta de tamanho de dados na memória.

Exemplo: Tratamento Seguro de Erros

try {
  int resultado = processarDadosCriticos(entrada);
} catch (Exception e) {
  logSeguranca("Tentativa de falha capturada: " + e.getMessage());
}

Evita que o sistema exponha rastros de pilha (stack traces) sensíveis para o usuário final.

Matéria 04

Banco de Dados

Modelagem relacional, controle de privilégios de acesso e segurança no armazenamento persistente de dados corporativos e pessoais.

Vetor de Ataque: SQL Injection

Injeção de comandos SQL maliciosos em campos de consulta ao banco.

Mitigação: Prepared Statements (Consultas Parametrizadas)

-- Forma Segura com Parâmetro
SELECT * FROM usuarios
WHERE email = ?;

O banco trata o dado fornecido estritamente como valor, nunca como código executável.
